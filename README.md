# 유이 아카이브

007로저가 매일 아침 X에 올리는 파이 네트워크 브리핑 **유이**를 날짜별로 모아 두는 사이트입니다.

- 사이트: https://m99500-lgtm.github.io/scribble--wall/
- X: https://x.com/minkyeungsoon31

## 기능

- 최신 유이부터 날짜별로 보기 (10일씩, "더 보기")
- 검색 (예: KYC, 거래소, 패스프레이즈)
- 🚨 사기 경보만 모아 보기, 이슈·유머·응원 한마디만 보기
- 날짜로 바로 가기, 날짜별 링크 복사 (예: `.../scribble--wall/#2026-11-25`)

## 새 유이 올리는 법

1. 저장소에서 `yui.md`를 열고 연필(✏️ Edit) 버튼을 누릅니다.
2. 설명 주석 바로 아래에 날짜 줄과 그날 유이를 붙여 넣습니다.

   ```
   ## 2026-11-26
   (X에 올린 유이를 그대로 붙여 넣기)
   ```

3. **Commit changes**를 누르면 1~2분 뒤 사이트에 나옵니다.

## 파일

- `index.html` — 사이트 화면 (서버·로그인·비밀키 없음)
- `yui.md` — 유이 글이 쌓이는 파일
- `.nojekyll` — GitHub Pages가 파일을 그대로 보여 주게 하는 빈 파일

예전 낙서벽(ScribbleWall) 코드는 git 기록에 남아 있습니다.
